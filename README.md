# Game Dev Portfolio 🎮🕹️
A gamified comic style game development portfolio with detailed breakdown of games, art, skills, about and other experiences in game development.

Live Link - https://deepdass.github.io/

## How To Setup and Run it Locally
First clone this repo using 
```bash
git clone https://github.com/deepdass/deepdass.github.io.git
```
Then Open it in any code editor like VS code, rider etc, then install a extensions called Live Server and enable it, now right click the index.html in the file explorer of the code editor and press open with Live Server - It should start locally in your browser.

## Features
- Comic style design - bold, matching color scheme and comic layout
- Animated hero collage with floating game panels
- Game cards with photo carousels and detailed game breakdowns pop ups
- 3D art & renders gallery
- Skills & contact section
- Scroll-reveal animations, wiggle effects, and ticker
- Responsive layout

## Showcased Games

### Tokyo Drift
Physics-focused arcade drifting game inspired by Japanese car culture. Vehicle having car properties similar to their real like counterparts with matching real-world torque & traction.
### Noroi
Fixed-camera survival horror inspired by original Resident Evil & Silent Hill. Simulates PS1-era visuals and limitations for a unique look.
### SkullWard
Pixelated 3D roguelike dungeon crawler with procedural generation, optimized to run on Raspberry Pi. Showcased at Hack Club Shiba (Tokyo) in a physical arcade cabinet!
### Gaspfornow (WIP)
First-person integration of Epic's GASP with Dual-mesh FPV system. Planning to make it into a fast-paced first-person zombie parkour game. With custom hero props made in Blender.
### FPS Learn
A learning project made to teach about the animation workflow in game dev and how to build a combat system using custom animations.
### Ruin Kingdom
Zone-based first-person RPG built to learn large-scale world design in UE5. Enemy AI, in-engine animations, custom shaders & melee combat.
### Island of Dead
My very first self-directed game - zero tutorials. Cute Chibi-style 2D zombie platformer with a companion character called ghosty. Where it all began.
